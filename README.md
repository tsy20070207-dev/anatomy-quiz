# 运动解剖学习题库（站点）

- 打开 `index.html`（站点根目录会自动加载它）即可刷题，进度保存在你自己的浏览器里。
- `anki-fill-cloze.csv`：107 道填空题的挖空卡 → 用 Anki 的 **Cloze** 模板导入。
- `anki-basic.csv`：446 张选择/判断/名词解释/简答问答卡 → 用 Anki 的 **Basic** 模板导入。
  手机端可先在浏览器点这些链接下载文件，再用 AnkiDroid / AnkiMobile 导入。

本目录由 `复习题库/scripts/07_build_deploy.py` 生成，请勿手工修改；
要更新内容，改完源文件后在 `复习题库/` 里执行 `bash scripts/deploy.sh`。
